## Scope

Deliver the opt-in **Werkschaft Lead Companion (desktop pet)** feature as a modular, pack-driven visual companion mounted once on the persistent Werkschaft dashboard outer shell (`dashboard.tmpl` / `shell.js`), defaulting strictly to **`off`**:

- **T0 opt-in configuration & live settings UI:** Scalar `dashboard.companion_*` keys mirrored across `ws` and `wsflow`, inspectable in Dashboard Settings, and broadcast live to the shell without page reloads.
- **Memory-first embedded & BYO pack serving (`performance.md`):** Serve an IP-clean embedded default pack alongside user-supplied local packs under `<config-home>/companions/<pack-id>/pack.json` with zero per-frame or per-request disk I/O.
- **App-scoped shell overlay & data-driven v3.1 Doll-Maker Canvas engine:** Persist one companion instance across session switches, anchor by default on the left session rail bottom divider (above `.rws-unreg` / `.rfoot`) so dense session panes stay unobstructed, subscribe to a lightweight active-view context/landmark relay from the active session iframe, and run a 3-layer extensible architecture: fixed low-level primitives (generic part/joint anchored `oscillate`/`keyframes`/`frames` tracks, whole-body stage physics, and prop trajectories), open `pack.json` asset dictionaries (`poses`, `gestures`, `expressions`, `props`, `fx` with `fallback` chains), and a declarative `scenarios` registry seeded with 12 built-in starter scenarios.
- **Optional agent director:** A lead-unaware lightweight sidecar that reads the visible session's recent activity and drives the companion in its pack persona's voice, kept strictly separate from the 0-token rules engine; settings split into a panel toggle plus a gear-opened floating modal. *(Partially superseded for the authorized Tier-2 `companion-work` session scope and Dual-Brain architecture only — see Non-Scope / Cross-Child Decisions, `(1737)=a`, `(1738)`, & `(1744)=a`.)*
- **Official 2D ship art polish gate (deferred, (133)=c):** Decouple final art refinement from engine delivery so official shipped 2D art passes explicit human visual sign-off against the v3.1 craft gates. The art pack ticket stays in `todo/` and is not a Done condition.
- **Pure-VRM renderer track (coexisting with 2D):** A second, lazy-loaded renderer selected per pack by `"schema": "ws-companion-vrm/v1"` (`renderer: "vrm"`): single-file `.vrm` drop-in, memory-first binary serving, a dedicated bottom-left VRM slot (`#rail-companion-slot`, landed in `344452e44` / `(148)=a` with responsive `220–360 px` width and `0 px` vertical jitter), and procedural 2-bone arm IK with 3D toon props, all driven by the same shared event/scenario/director backbone as the 2D renderer. The 2D bullets above (rail-bottom home, `pack.json` asset dictionaries, scenarios registry, paper-doll wardrobe) describe the `ws-companion/v1` renderer unless a bullet says otherwise.

## Non-Scope

- Enabling the companion by default for any user or package (`ws` and `wsflow` both default `dashboard.companion_enabled` to `false`).
- Side-view walking articulation (`W. Side-Walk`) or bare-skin knee/hip joint cuts in v1/v3.1.
- Shipping any third-party or community character assets inside the public repository.
- Modifying the user's primary coding lead's orchestration, ticket workflows, or session lifecycle semantics based on companion state. *(Supersession note, `(1795)=a` superseding `(1737)=a`, `(1738)`, & `(1744)=a`: 3-Tier Companion Architecture — Tier-0 (`dashboard-companion-reflex.js`) provides 0ms deterministic client physical reflex; Tier-1 (`companion-body`) is a lightweight pure-cosmetic Puppeteer observing Brain's hosted session and emitting VRM/stage-quip `CompanionCommand`s with zero coding, tool, memory-write, or direct-user/messenger authority; Tier-2 (`companion-work` Brain) is an unlisted (`Listed = false`) Mobile Full Lead owning direct Messenger conversation, Persona, and Soul/Episodes memory (`remember_soul`, `remember_episode`, `recall_memory`) plus `ws/daemon.*` access under `(1796)=a` fail-closed approval gates, while keeping the user's primary coding lead completely untouched.)*
