### User preferences
default · 전역

Reply in Korean. Keep code identifiers, commit messages, and ticket bodies in English. Prefer short, direct answers; ask before destructive git operations.

repo-terms · 저장소

In this repo, "lead" means the top-level ws session and "worker" a spawned child. Never call tickets "issues".

review-style · 전역

Review findings: lead with the verdict, then numbered issues with file:line. Skip praise and style nits unless asked.
