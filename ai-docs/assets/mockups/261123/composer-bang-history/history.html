"전체 지우기"는 2단계 확인(클릭하면 빨간 확인 상태, 3초 후 복귀). 히스토리가 비어 있으면 팝업 자체를 띄우지 않음. 결정 E

오너 결정 필요 항목 (권장안)

  1. A. 행 메타 정보 — 상대 시간 + 종료 코드 칩 표시? 권장: 둘 다 표시(종료 코드는 실행 완료 후 기록, 없으면 칩 생략).
  2. B. Enter 동작 — 선택 행에서 첫 Enter는 명령을 입력창에 채우고, 두 번째 Enter는 채운 명령을 실행합니다. ↑/↓는 선택 행을 이동하고 Tab은 선택 명령을 자동완성합니다.
  3. C. 저장 범위 — 워크트리별 vs 전역. 권장: 워크트리별(명령이 cwd 의존적), 전역 토글은 후속.
  4. D. 크기 제한 — 권장: 최대 200개, 같은 명령은 중복 저장 없이 맨 위로 이동, 초과 시 오래된 것부터 삭제, 항목당 최대 2 KB.
  5. E. 전체 지우기 — 푸터 링크 + 2단계 확인. 권장: 포함(개별 ✕만으로 200개 정리는 번거로움).
  6. F. 열리는 시점 — ! 입력 직후 자동 vs ↑키로만. 권장: 자동 오픈. 첫 Esc는 팝업만 닫고 두 번째 Esc가 기존 bang 종료(기존 Esc 동작 보존).
